## Technical Scope & Model Boundaries
- Target relational data modeling covering 20 base tables + 1 analytical view (`v_student_leaderboard_tiers`) in PostgreSQL 16.
- 8 canonical ENUM types: `user_role_enum`, `student_type_enum`, `lecture_type_enum`, `access_grant_type_enum`, `payment_method_enum`, `payment_status_enum`, `submission_status_enum`, `point_action_type_enum`.
- Entitlements modeled in `lecture_access` (no generic "enrollments" table).
- Primary keys are UUIDs across all entity tables.
- Foreign key constraints: `ON DELETE SET NULL` and `CASCADE` enforced and verified on PostgreSQL 16.6 runtime probe (invalid FK rejected with `pgcode 23503`).

## Known Disclosures & Invariant Policies
1. **Schema Parity & Legacy Table Deviation:** Canonical PostgreSQL contains 20 base tables + 1 view (`v_student_leaderboard_tiers`); SQLite contains 21 base tables + 1 view due to the legacy `password_reset_otps` table. This extra table is a backward compatibility deviation observed from 5 immutable tests in external `test_security_and_hardening.py` (AST-verified: `test_sec_16_otp_expiry_enforcement`, `test_sec_17_otp_single_use_replay_prevention`, `test_sec_18_otp_brute_force_max_attempts_blocked`, `test_sec_19_otp_phone_sanitization`, `test_sec_27_otp_rate_limiting_and_chronological_ttl_invariant`); this is an observed legacy fixture dependency, not proof of an intentional business decision, and no full 1:1 table count parity is claimed.
2. **Forensic WORM Immutability & Admin Hard Delete:** The `admin_audit_logs` table enforces OWASP A09 immutability via PL/pgSQL triggers (`fn_prevent_audit_log_modification()`). This trigger vetoes cascade hard deletion of administrator users, ensuring forensic audit records cannot be purged.
3. **Future FK Refactoring Proposal:** An architectural proposal to convert foreign key `ON DELETE CASCADE` actions to `ON DELETE RESTRICT` remains an open proposal and is NOT implemented in current source DDL. Current condition relies on existing DDL constraints and WORM trigger vetoes.
4. **Artifact Location:** Delivered schema files and adapter are external standalone files, not shipped in repository.
5. **Runtime Verification Evidence:** Verified via 105 tests on in-memory SQLite (standalone legacy database test suite) and 14 standalone runtime probes on portable PostgreSQL 16.6 (port 5433, see [evidence/pg-runtime-summary.md](./evidence/pg-runtime-summary.md)). Docker/production unverified. Baselines are strictly separated.
