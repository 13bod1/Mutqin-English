## Technical Scope & Harness Configuration
- Configuration and connection adapter abstraction supporting dual-engine execution: SQLite (local/testing) and PostgreSQL 16 (production).
- Adapter registers custom SQLite functions (e.g., `REGEXP`, `uuid_generate_v4()`) to emulate PostgreSQL extensions in-memory.
- Automated tests instantiate in-memory SQLite instances (`:memory:`), providing ephemeral isolation without modifying on-disk files.
- Dedicated standalone runtime verification harness (`runtime_probe.py`) established for PostgreSQL 16.6 with `psycopg2-binary 2.9.13`.
